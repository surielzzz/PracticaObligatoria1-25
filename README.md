# 0.0. Instalación
Para ejecutar este programa se necesita tener instalado el JDK. Comprueba que Java esté ubicado en:

C:\Program Files\Java

Luego:

1. Abre “Editar las variables de entorno del sistema”
2. En “Variables de entorno”, busca “Path”
3. Añade la ruta del bin de Java, por ejemplo:

C:\Program Files\Java\jdk-18.0.2.1\bin

Guarda los cambios y podrás ejecutar el archivo .bat incluido con el programa.

---

# 0.1. Descarga
En el repositorio de GitHub:

1. Haz clic en el botón verde “Code”
2. Selecciona “Download ZIP”
3. Descomprime el archivo
4. Ejecuta el archivo .bat para iniciar el simulador

# 0.4. Funcionamiento

---

# 1. Estado de las habitaciones

## 1.1. Mostrar listado
Se mostrará un listado con todas las habitaciones, indicando si están libres u ocupadas.

## 1.2. Regresar al menú
Pulsa cualquier tecla para volver al menú principal.

---

# 2. Reservar una habitación

## 2.1. Selección de tipo de habitación
Podrás elegir entre:

- Habitación individual  
- Habitación doble  

## 2.2. Recolección de datos
El sistema pedirá:

- Primer nombre  
- Segundo nombre  
- DNI  

Es importante escribir los datos correctamente.

## 2.3. Confirmación de reserva
Al finalizar aparecerá:

“HABITACIÓN --- RESERVADA. Gracias por su reservación.”

Luego deberás introducir el número 3 para volver al menú principal.

---

# 3. Realizar checkout

## 3.1. Introducción de datos
Se pedirán los mismos datos registrados en la reserva, además de la fecha de salida.  
Los datos deben coincidir exactamente.

## 3.2. Factura
Se generará una factura detallada con el coste total de la estancia.

## 3.3. Pago y cambio
Se solicitará el pago en efectivo. El sistema calculará el cambio automáticamente y te devolverá al menú principal.

---

# 4. Menú de administrador

## 4.1. Registro
Para entrar deberás introducir:

Usuario: canela  
Contraseña: 1961  

Una vez dentro aparecerá el menú administrativo.

---

## 4.1.1. Consultar ingresos y reservas
Permite visualizar:

- Ingresos totales  
- Número de reservas actuales  

Los datos se actualizan según el uso del programa.

---

## 4.1.2. Consultar monedas restantes
Muestra el inventario actual de billetes y monedas disponibles para el cambio.

---

## 4.1.3. Apagar sistema
Cierra por completo el software.  
Para volver a utilizarlo, deberás ejecutar de nuevo el archivo .bat.
